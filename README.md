# Установка AmneziaWG с HTTPS-панелью

## Что потребуется

- Управляющая машина с Ubuntu 24.04, доступом в интернет и запуском под root.
- VPN-сервер с Ubuntu 24.04 amd64, публичным IPv4-адресом и доступом root по SSH на порту 22.
- Разрешённые у провайдера UDP 51820 для VPN и TCP 443 для HTTPS-панели.

## Запуск

Скопируйте `deploy-amneziawg.sh` на управляющую машину и запустите из терминала под root:

```bash
bash deploy-amneziawg.sh
```

Скрипт спросит только публичный IP-адрес сервера и пароль root. Ввод пароля скрыт.
Зависимости управляющей машины устанавливаются автоматически, проект скачивается
в соседнюю папку `AmneziaWG-Web-Panel`. На минимальном образе VPS скрипт заранее
установит Python и модуль apt для Ansible.

Далее выполняются проверка SSH, Ansible ping, lint, тесты, проверка синтаксиса,
предварительный запуск `--check --diff`, установка и повторное применение с
проверкой `changed=0`. Скрипт также исправляет повторную загрузку ключа Amnezia:
его отпечаток проверяется при каждом запуске, а существующий файл используется повторно.

## Вход в панель

После установки откройте показанный скриптом адрес, например
`https://vpn-server.example/`, заменив имя сервера его IP-адресом.
Панель сразу покажет форму ввода пароля Amnezia. Логин и отдельный пароль nginx
не требуются. nginx обеспечивает HTTPS и передаёт запросы внутренней панели,
которая сохраняет собственную проверку пароля.

Пароль Amnezia генерируется автоматически при первой установке и сохраняется
между запусками. На VPS он находится в `/opt/amneziawg/password.txt`.
Скрипт также сохраняет его в приватную папку `amneziawg-access-*` рядом с собой:

- `password.txt` — единственный пароль для входа в панель;
- `cert.pem` — публичный сертификат HTTPS-панели;
- `certificate-sha256.txt` — SHA-256-отпечаток сертификата.

Папка имеет права 700, файлы — 600. Пароли не выводятся в отчёт установки.
Сертификат самоподписанный: перед подтверждением исключения в браузере сравните
его отпечаток с показанным скриптом. Для VPN используются UDP 51820,
для панели — HTTPS на TCP 443; внутренний сервис панели слушает только localhost.

## Обновление уже установленной панели

Замените старый `deploy-amneziawg.sh` новым файлом и запустите его из прежней папки:

```bash
bash deploy-amneziawg.sh
```

Скрипт обновит уже скачанный проект, уберёт первое окно входа nginx и применит
конфигурацию. Пароль Amnezia, VPN-ключи и клиенты сохраняются. Старые файлы доступа
nginx на сервере удаляются после проверки панели. Если браузер держит прежнее
окно входа, закройте его и заново откройте адрес панели.

При ошибке выполнение останавливается. Устраните причину и повторите запуск из
той же папки. Скрипт сохраняет посторонние локальные изменения проекта; если
исправления конфликтуют с ними, он остановится до подключения к VPS.
Установка не выполняет полное обновление ОС или перезагрузку и не меняет SSH-правила.

Если APT занят автоматическим обновлением Ubuntu или другой установкой пакетов,
скрипт ожидает освобождения блокировки до 15 минут на соответствующем шаге.
Это относится к подготовке управляющей машины, минимального VPS и пакетам Ansible.
При превышении срока выполнение остановится: дождитесь окончания обновления
и повторите запуск. Lock-файлы не удаляются, процесс обновления не останавливается.

## Проверка VPN

Создайте клиента в панели, скачайте конфигурацию и подключитесь через AmneziaVPN
из другой сети. Проверьте подключение, DNS и выход в интернет через VPN.
Серверные проверки установки не подтверждают доступность через внешний firewall провайдера.
